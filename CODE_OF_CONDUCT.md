# Code of conduct

This project is a small tool with a small group of people around it. The standard is ordinary: be precise, be patient, and criticise the change rather than the person.

## Expected

- Read the report and the diff before answering.
- Disagree in the open, on the issue or the pull request.
- Assume the other person has not seen the file you have open.

## Not accepted

- Insults, slurs, or harassment.
- Publishing someone else's private information.
- Repeated bad-faith argument after a maintainer has closed the thread.

## Reports

Open a private security advisory, or an issue if the matter is already public, and mention this file. Prafull Joshi maintains the repository and will answer. A report that concerns the maintainer can be sent to another owner of the repository if one exists.

Anyone asked to stop a behaviour in this list is expected to stop. Maintainers may close issues, reject patches, or block accounts that will not.
